The Dijkstra’s algorithm I developed is used to find the shortest path between two vertices in a graph. The program reads graph information from JSON files and allows the user to select a graph, view its vertices, edges and degrees, and choose starting and ending vertices. The algorithm then calculates the shortest path and total distance between the selected vertices. The program also includes exception handling to prevent self-loops and duplicate edges. Python libraries such as JSON, Dataclasses and Heapq are used in the implementation. The work also considers the algorithm’s time complexity and possible improvements using an adjacency list and priority queue.
